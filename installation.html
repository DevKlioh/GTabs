Installation

  1. Stop the server.
  2. Place GTabs-v1.0.0.jar in plugins/.
  3. Install current compatible ProtocolLib and Floodgate for the latest BedrockPOV UserLines path.
  4. Optionally install PlaceholderAPI and LuckPerms.
  5. Start the server and edit GTabs YAML files.
  6. Run /gtabsreload after YAML changes.
plugins/GTabs/
├── config.yml
├── scoreboard.yml
└── animations.yml
Use a full server restart after changing the GTabs JAR, ProtocolLib, Floodgate, or renderer-related dependencies.
