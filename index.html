Introduction

GTabs gives server owners control over Java TAB formatting, rank sorting, Java/Bedrock scoreboards, reusable animations, platform-aware UserLines, native health displays and placeholders. Java and Bedrock layouts can be tuned independently for a polished server identity.

Latest Features

  • Configurable Java TAB header/footer and player-name format.
  • LuckPerms rank sorting with real IGN support.
  • Separate Java and Bedrock scoreboards.
  • Java, Bedrock and BedrockPOV UserLines with individual offsets.
  • Multiverse-safe non-passenger UserLines architecture.
  • ProtocolLib + Floodgate path for Bedrock POV UserLines handling.
  • Native %gtabs_health% with 8 structures and automatic colors.
  • Native colored %player_ping% number.
  • RGB/hex, gradients, PlaceholderAPI and animations.
